### 💻 Sobre

Full Stack Developer com 5 anos de experiência, atualmente na **PitchYes**, startup de automação de vendas por voz com IA. Projetei do zero uma arquitetura de filas distribuídas (**NestJS + BullMQ + Redis**) que aumentou o volume de chamadas processadas em **+273%** (306K → 1,14M/mês). Foco em back-end escalável, infraestrutura self-hosted e integrações com APIs de terceiros (Meta/WhatsApp, Instagram, TikTok).

- 🏗️ Arquitetura de filas assíncronas e sistemas orientados a eventos (Change Streams)
- 🧱 Migração de bases Express → NestJS com Clean Architecture
- 🔧 Manutenção e refatoração de códigos legados, com foco em performance e escalabilidade
- 🤖 Orquestração de agentes de IA para automação de fluxos de desenvolvimento
- 🐳 Infraestrutura self-hosted: MongoDB Replica Set, Redis, Nginx + SSL, Docker Compose, MinIO
- 🔌 Integrações: Meta Graph API, WhatsApp Business Cloud API (Embedded Signup), Instagram/TikTok API
- 📚 Cursando Análise e Desenvolvimento de Sistemas — SENAC Goiás
